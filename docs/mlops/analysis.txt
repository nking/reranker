Hugging Face has Qwen/Qwen2.5-0.5B-Instruct

HuggingFace trl is chosen
   - robust APIs
   - lots of documentation
   - actively maintained and updated
   - SFTrainer

Optuna is chosen for HPO:
   - native support by Hugigng Face transformers and trl
   - runs locally instead of over gRPC, in-memory database,
   - offers advanced built-in pruners

The pretrained LLM of choice at this time:
   Qwen/Qwen2.5-0.5B-Instruct
   - uses full softmax self-attention in all 24 layers, giving it 4x as many all-to-all
     cross-item comparison layers for short (~250-token) ranking prompts
   - standard matrix-multiplication attention so should work well on CPU and T4x2 GPUs
   - instruction following
   - more resilient to the diversity of system prompts
   - Long-context Support up to 128K tokens and can generate up to 8K tokens.
   - Multilingual support
   - Training Stage: Pretraining & Post-training
   - Context Length: Full 32,768 tokens and generation 8192 tokens
   the rest of the model card: https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct

Quantization and Lora will be used to reduce model size.
